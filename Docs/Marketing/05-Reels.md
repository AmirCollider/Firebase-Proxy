## راه صفر — امروز، بدون هیچ ابزاری

قبل از ریلز، این را بکن، چون **صفر کار دارد**:

هیچ تدوینی لازم نیست. یوتیوب افقی می‌خواهد و کلیپ‌های تو افقی‌اند.
عنوان و توضیح در [`07-Channels.md`](07-Channels.md) آماده است. یوتیوب یک
موتور جستجوست — این ده ویدیو سه سال دیگر هم بازدید می‌آورند، برخلاف
هر ریلزی که بسازی.

**این کار مهم‌تر از کل بقیه‌ی این فایل است.** اول این، بعد ریلز.

## راه یک — خودت، پانزده دقیقه برای هر ریلز

با **CapCut** (رایگان، موبایل و دسکتاپ). اگر در دسترس نبود، هرکدام از
این‌ها همین کارها را دارند: **VN Video Editor**، **Canva**،
**Shotcut** (رایگان، آفلاین، بدون حساب کاربری).

دستور دقیق، برای هر کلیپ یکسان:

```
۱. پروژه‌ی جدید ← نسبت 9:16
۲. کلیپ MP4 را وارد کن
   ← بزرگش کن تا عرض کامل قاب را بگیرد
   ← عمودی وسط قاب بگذارش (بالا و پایین خالی می‌ماند)
۳. رنگ پس‌زمینه ← #0B1220  (سرمه‌ای تیره، مثل سایت خودت)
۴. متن قلاب  ← بالای قاب، از ثانیه‌ی ۰ تا ۳
   فونت درشت، سفید، وسط‌چین
۵. متن زیرنویس ← پایین قاب، طبق زمان‌بندی برگه‌ی پایین
۶. متن CTA ← دو ثانیه‌ی آخر: "amircollider.com · free"
۷. موسیقی ← از کتابخانه‌ی خود اپ، دسته‌ی "tech / minimal / lo-fi"
   ولوم ۲۰٪
۸. خروجی ← 1080×1920 · 30fps
```

بار اول بیست دقیقه طول می‌کشد. بار دوم به بعد، ده دقیقه — چون فقط
متن‌ها را عوض می‌کنی. **پروژه‌ی اول را ذخیره کن و بقیه را از رویش کپی کن.**

## راه دو — بسپار به کسی، با پرداخت کریپتو

اگر واقعاً نمی‌خواهی خودت انجامش بدهی، این کار **بیرون‌سپاری‌شدنی** است و
گران هم نیست. کل بسته‌ی ده ریلز، بین ۵۰ تا ۱۵۰ دلار.

مهم: بیشتر پلتفرم‌های فریلنسری برای تو تسویه‌ی معکوس دارند (تو پرداخت‌کننده‌ای،
نه گیرنده) که ساده‌تر است، ولی همچنان کارت می‌خواهند. این‌ها با کریپتو کار می‌کنند:

| جا | چرا | چطور |
|---|---|---|
| **[LaborX](https://laborx.com)** | فریلنس بومیِ کریپتو. پرداخت با USDT/BTC، اسکرو دارد. آگهی‌های «short-form video editor, crypto pay» روزانه آن‌جاست | آگهی بگذار، متن پایین |
| **Fiverr** | بزرگ‌ترین انتخاب و ارزان‌ترین. مشکل: کارت می‌خواهد | با یک گیفت‌کارت Fiverr که با کریپتو خریده‌ای |
| **پونیشا / کارلنسر** | ایرانی، پرداخت ریالی، بدون دردسر تحریم | تدوینگر ریلز فارسی زیاد دارند |
| **Upwork** | کیفیت بالاتر، گران‌تر، کارت لازم | آخرین گزینه |

**متن آگهی — انگلیسی، کپی کن:**

```
Title: 10 short vertical videos from existing screen recordings (9:16, captions)

I have 10 finished screen recordings of a Unity editor tool. Each is
14-21 seconds, 16:9, no editing needed to the footage itself.

I need each one turned into a 9:16 reel:
  - footage centred on a dark background (#0B1220)
  - a hook line at the top, on screen for the first 3 seconds
  - captions at the bottom, timings and text supplied by me
  - a 2-second end card with a URL
  - light royalty-free background music at low volume
  - export 1080x1920, 30fps, mp4

Every reel uses the same template — only the text changes. I will send
the footage, the exact hook and caption text for all 10, and a reference
frame. Consistency matters more than creativity.

Deliverable: 10 mp4 files + the project file so I can make more myself.
Payment: USDT (TRC-20), escrow, half up front.
Budget: $80-150 for all 10.
```

آن «project file» را حتماً بخواه. با آن، ریلز یازدهم به بعد را خودت
در پنج دقیقه می‌سازی.

## قالب ثابت — یک بار بساز

هر ده ریلز یک قالب دارند. یک بار درستش کن، ده بار متنش را عوض کن:

```
canvas      1080 × 1920
پس‌زمینه     #0B1220
ویدیو        عرض کامل، عمودی وسط
متن قلاب     بالا، 25٪ از بالا، سفید #FFFFFF، درشت، وسط‌چین، سایه
زیرنویس      پایین، 25٪ از پایین، سفید، متوسط، وسط‌چین
CTA          دو ثانیه‌ی آخر، وسط قاب، #14808C پشت متن سفید
موسیقی       ولوم ۲۰٪
```

`#14808C` همان رنگ برند سایت خودت است (در بج‌های README دیده می‌شود).
همان را نگه دار تا هر ویدیو، هر پست و خود سایت یک چیز به نظر بیایند.
