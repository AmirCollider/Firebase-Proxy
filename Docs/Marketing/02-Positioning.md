# جایگاه محصول — محصول باید چه چیزی صدا بزند

هر متنِ این فایل آماده‌ی کپی-پیست است. جایی که سه زبان آمده، هر سه لازم است.

---

## تغییر اصلی

| | |
|---|---|
| **الان** | یک ابزار مستندسازی که *اتفاقاً* برای هوش مصنوعی هم خوب است |
| **باید** | راهی که کل پروژه‌ی یونیتی‌ات را به هوش مصنوعی می‌دهد — که *اتفاقاً* یک سایت مستندات کامل هم می‌سازد |

همان محصول است. همان کد است. فقط ترتیب دو جمله عوض می‌شود، و آن ترتیب
تفاوت بین «جالبه» و «همین الان لازمش دارم» است.

**چرا:** «مستندسازی» کارِ فردا است، همیشه. «هوش مصنوعی‌ام پروژه‌ام را
نمی‌فهمد» مشکل امروز است، و کسی که با آن درگیر است همین حالا در حال
جستجو کردن است.

## پاراگراف معرفی (elevator)

**انگلیسی**
```
Unity DocSnap walks every Scene, Component and serialized field in your
project and writes one ai-bundle.md you can paste into Claude, Cursor or
Copilot — plus a full offline HTML site with search, a health report and
clickable references for the humans on your team.

Editor-only. Zero runtime cost, zero build size, zero dependencies.
The entire exporter is free, with no time limit.
```

**فارسی**
```
Unity DocSnap تمام سین‌ها، کامپوننت‌ها و فیلدهای سریالایزشده‌ی پروژه‌ات را
می‌خواند و یک فایل ai-bundle.md می‌سازد که مستقیم در Claude یا Cursor
پیست می‌کنی — به‌علاوه‌ی یک سایت HTML آفلاین با جستجو، گزارش سلامت پروژه
و رفرنس‌های قابل کلیک، برای آدم‌هایی که در تیم هستند.

فقط داخل ادیتور. صفر هزینه‌ی رانتایم، صفر حجم اضافه در بیلد، صفر وابستگی.
کل خروجی‌گیر رایگان است و محدودیت زمانی ندارد.
```

**日本語**
```
Unity DocSnap はプロジェクト内のすべてのシーン、コンポーネント、シリアライズ
フィールドを走査し、Claude や Cursor にそのまま貼り付けられる ai-bundle.md
を 1 つ書き出します。さらに、検索・プロジェクト健全性レポート・クリック可能な
参照を備えた完全オフラインの HTML サイトも生成します。

エディタ専用。ランタイムコストゼロ、ビルドサイズ増加ゼロ、依存関係ゼロ。
エクスポーター本体は期限なしで無料です。
```

## جمله‌ی تمایز — این را همه‌جا بگو

اکوسیستم Unity MCP الان داغ است و رقیب مستقیم به نظر می‌رسد. نیست، و
تفاوت به نفع توست:

**انگلیسی**
```
MCP servers need Unity open and running. DocSnap gives you a file.
It works offline, in any tool, in any chat window, on a machine that has
never had Unity installed — and it still reads the same six months from now.
```

**فارسی**
```
سرورهای MCP لازم دارند یونیتی باز و در حال اجرا باشد. DocSnap یک فایل
به تو می‌دهد. آفلاین کار می‌کند، در هر ابزاری، در هر پنجره‌ی چتی، روی
کامپیوتری که اصلاً یونیتی رویش نصب نشده — و شش ماه دیگر هم همان را می‌گوید.
```

این تنها جمله‌ای است که هم موضع تو را روشن می‌کند و هم به موجِ موجود
سوار می‌شود بدون این‌که ادعای رقابت کند.

## سه دلیل خرید، به ترتیب قدرت

هر جا سه بولت لازم داشتی — صفحه‌ی محصول، کپشن، ایمیل — همین سه‌تا:

```
1. Paste your whole project into an AI, once.  (ai-bundle.md)
2. See exactly what changed since last export. (Changes page)
3. Read the project with no Unity installed.   (offline HTML site)
```

اولی می‌فروشد. دومی تکرار خرید می‌سازد. سومی به مدیر و آرتیست تیم می‌فروشد.

## کلمات کلیدی که باید هدف بگیری

این‌ها را در توضیح گیت‌هاب، README، عنوان ویدیوهای یوتیوب و
`keywords` صفحه‌های سایت پخش کن:

**اولویت اول — قصد خرید بالا، رقابت کم**
```
give claude my unity project
unity project context for AI
unity project to markdown
export unity scene hierarchy
unity project ai bundle
cursor unity context
```

**اولویت دوم — دسته‌ی کلاسیک**
```
unity documentation generator
unity project documentation
unity scene documentation export
unity editor tool documentation
unity offline documentation
```

**اولویت سوم — دردهای همسایه (برای محتوا، نه فروش مستقیم)**
```
unity missing script finder
unity broken reference report
unity project audit tool
unity asset import settings report
```

عبارت اول (`give claude my unity project`) در حال حاضر عملاً هیچ نتیجه‌ی
اختصاصی ندارد. یک صفحه یا یک ویدیوی دقیق با همین عنوان، جای خالی است.

## یک هشدار درباره‌ی بستن سورس

در سپتامبر ۲۰۲۶ DocSnap از MIT به یک اسمبلی کامپایل‌شده منتقل شد. حق خودت
است و دلیل تجاری‌اش روشن است، ولی این را بدان که چه چیزی را با آن بستی:

- **OpenUPM** فقط پکیج متن‌باز می‌پذیرد ⟵ در دسترس نیست
- فهرست‌های `awesome-unity` تقریباً همیشه متن‌باز می‌خواهند ⟵ در دسترس نیست
- بخشی از برنامه‌نویس‌ها DLL بدون سورس را در پروژه نمی‌آورند

نمی‌گویم برگرد. می‌گویم دو کار جبرانی بکن، هر دو ارزان:

1. **DirectTMP را جدی بگیر.** MIT است، رایگان است، و همان کارهایی که برای
   DocSnap ممنوع شد برای آن باز است. قیف اصلی‌ات آن است. ([`07`](07-Channels.md#openupm))
2. در README و صفحه‌ی محصول، همان بندی که در CHANGELOG نوشتی — اجازه‌ی
   صریح دیکامپایل برای اطمینان از امن‌بودن — را **بالا** بیاور، نه در
   CHANGELOG. آن جمله دقیقاً همان نگرانی را جواب می‌دهد و الان جایی است
   که کسی نمی‌خوانَدش.
