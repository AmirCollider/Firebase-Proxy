# اینستاگرام — کیت کامل اکانت کاری

قبل از هرچیز، یک بار صادقانه: **اینستاگرام مستقیماً ابزار یونیتی نمی‌فروشد.**
کسی که DocSnap را می‌خرد آن را در یوتیوب، گوگل یا انجمن پیدا می‌کند، نه در
اکسپلور اینستاگرام.

پس چرا بسازیمش؟ سه دلیل واقعی:

1. **بازار فارسی‌زبان.** DirectTMP دقیقاً درد شماره‌ی یک برنامه‌نویس فارسی
   یونیتی را حل می‌کند و آن جامعه *در اینستاگرام است*، نه در ردیت.
2. **اعتبار.** وقتی به یک یوتیوبر ایمیل می‌زنی، اول اسمت را سرچ می‌کند.
   یک اکانت مرتب با ده پست، جواب «این کیه؟» است.
3. **بایگانی ریلز.** همان ویدیوهایی که برای اینستاگرام آماده می‌کنی،
   عیناً در YouTube Shorts و TikTok هم می‌روند — و آن دو **می‌فروشند**.
   یعنی کار اینستاگرام دو بار مصرف می‌شود.

با همین انتظار جلو برو. اگر شش ماه دیگر هزار فالوئر داشتی و پنج فروش،
موفق بوده، نه شکست‌خورده.

**پست ۸ · تک‌عکس · ستون D**

> اسکرین‌شات یک بخش از CHANGELOG ۱.۰.۳

```
Shipping a bug fix that took two days to understand.

Every string in a project's UI was missing from the AI summaries — button
labels, menu titles, dialogue. The cause was a rule that is otherwise
right: the summary only expands your *own* scripts, because expanding
Unity's components too would make it the exhaustive export it exists as
an alternative to. And every text component in Unity belongs to Unity
or to TextMesh Pro.

So the fix isn't a list of component types — a list is wrong the moment
a project uses a label widget I've never heard of. The rule is the
*field*: anything with a serialized string field named `text`, whoever
wrote it.
```
```
یک باگ که دو روز طول کشید تا بفهممش.

همه‌ی متن‌های رابط کاربری پروژه از خلاصه‌های هوش مصنوعی غایب بودند — لیبل
دکمه‌ها، عنوان منوها، دیالوگ‌ها. علتش قانونی بود که در بقیه‌ی موارد درست
است: خلاصه فقط فیلدهای اسکریپت‌های *خودِ* پروژه را باز می‌کند، چون اگر
کامپوننت‌های یونیتی را هم باز می‌کرد، می‌شد همان خروجی کاملی که قرار بود

می‌شود که پروژه‌ای از ویجتی استفاده کند که من نشنیده‌ام. قانون، خودِ
```

ماه دوم را از صفر ننویس. این را انجام بده:

1. در Insights ببین **کدام سه پست بیشترین Reach** را گرفتند
2. از هر کدام، سه نسخه‌ی دیگر بساز — همان ایده، قلاب متفاوت
3. ستون C را بیشتر کن اگر فالوئر کند رشد کرد؛ ستون A را بیشتر کن اگر
   کلیک روی لینک کم بود

و مهم‌تر از همه: **هر ریلزی که اینجا می‌گذاری را همان روز در
YouTube Shorts هم بگذار.** همان فایل، همان کپشن. یوتیوب جستجو دارد و
اینستاگرام ندارد — یعنی همان ویدیو آن‌جا سال‌ها کار می‌کند.
