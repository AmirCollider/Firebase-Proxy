یک ایمیل، هزاران خواننده که *دقیقاً* برنامه‌نویس یونیتی‌اند.

هفتگی، اختصاصاً یونیتی، فعال و منتشرشونده در ۲۰۲۶
([بایگانی شماره‌ها](https://gamedevdigest.com/digests.html)).

- **ایمیل:** `contact@unity3dreport.com`

## ۲. یوتیوبرها — بیشترین بازده، کندترین

یوتیوب برای ابزار یونیتی ۳۰ تا ۵۰ درصد ترافیک می‌سازد. یک ویدیوی
یک یوتیوبر متوسط، از سی ریلز اینستاگرام بیشتر می‌ارزد.

### چطور آدرسشان را پیدا کنی

هیچ آدرسی را از جایی حدس نزن. مسیر درست:

```
کانال یوتیوب ← تب "About" یا "درباره" ← بخش "Details"
← "View email address" ← کپچا ← آدرس واقعی کسب‌وکار
```

این آدرسی است که خودشان برای همکاری گذاشته‌اند و ایمیل به آن اسپم نیست.

### چه کسانی — به ترتیب اولویت

**دسته ۱ — کانال‌های «ابزار و ورک‌فلو» یونیتی.** این‌ها بهترین هدف‌اند:
مخاطبشان دقیقاً کسی است که ابزار می‌خرد، و همیشه دنبال موضوع برای
ویدیوی بعدی‌اند.

در یوتیوب این عبارت‌ها را جستجو کن و کانال‌هایی با **۲۰ تا ۲۰۰ هزار**
مشترک را جدا کن:

```
unity editor tools
unity workflow tips
unity asset review
unity productivity
unity tools you should know
```

**چرا ۲۰ تا ۲۰۰ هزار و نه بیشتر:** کانال‌های خیلی بزرگ صف اسپانسر
دارند و به ایمیل سرد جواب نمی‌دهند. کانال‌های این اندازه هم مخاطب
واقعی دارند هم ایمیل را می‌خوانند.

**دسته ۲ — کانال‌های «AI + کدنویسی»**، که ممکن است اصلاً یونیتی‌کار
نباشند ولی درباره‌ی context دادن به Claude و Cursor ویدیو می‌سازند.
زاویه‌ی تو آن‌جا تازه‌تر است چون کسی این را برای یونیتی حل نکرده.

```
cursor context
claude code tips
ai coding workflow
```

**دسته ۳ — یوتیوبرهای فارسی‌زبان یونیتی.** رقابت تقریباً صفر، و
DirectTMP برای مخاطبشان یک هدیه‌ی واقعی است.

## ۳. ابزارهای مکمل — بهترین شانس جواب گرفتن

این‌ها رقیب تو نیستند و می‌دانند که نیستند. یک لینک متقابل با
اکوسیستم Unity MCP از هر ایمیل سردی ارزشمندتر است.

| جا | چه کسی | چطور |
|---|---|---|
| [CoplayDev/unity-mcp](https://github.com/CoplayDev/unity-mcp) | نگه‌دارنده‌ها | GitHub Discussion یا Issue، نه ایمیل |
| [CoderGamester/mcp-unity](https://github.com/codergamester/mcp-unity) | نگه‌دارنده | همان |
| [Coplay](https://coplay.dev) | شرکت | فرم تماس سایت |

```
Subject: Complementary tool — static Unity project export for offline AI context

Hi,

I maintain Unity DocSnap, an Editor-only tool that exports a whole Unity
project — every Scene, Component and serialized field — into a single
ai-bundle.md, plus an offline HTML site.

I don't think we overlap, and I think we're better together. MCP is for
"change this scene for me": a live Editor, real actions. DocSnap is for
"here is my project, help me think": a file that works with Unity closed,
on another machine, or in a chat six months from now. People who want one
usually want the other.

If a line in your README under something like "see also" would make sense
to you, I'd be glad to add the same for you in mine — happy to go first.

  https://github.com/AmirCollider/UnityDocSnap

Either way, thanks for building the MCP side. It made explaining what my
tool is for much easier.

Amir
```

جمله‌ی «happy to go first» را نگه دار. **اول لینک آن‌ها را به README
خودت اضافه کن، بعد ایمیل بزن.** آن‌وقت درخواست نیست، جبران است.

## ۴. دیسکورد — بدون ایمیل، اثر سریع

سرورهایی که ارزشش را دارند:

| سرور | کانال | نکته |

| Game Dev League | `#promotion` | فعال، پذیرا |
| دیسکوردهای یوتیوبرهای بالا | معمولاً `#self-promo` | بهترین کیفیت مخاطب |
| دیسکوردهای فارسی برنامه‌نویسی/بازی‌سازی | هرجا | DirectTMP این‌جا برنده است |

**قانونی که همه‌جا صادق است:** دو هفته فقط به سؤال بقیه جواب بده،
بدون یک بار اسم بردن از محصولت. بعد بگذارش. کسی که در `#self-promo`
اولین پیامش تبلیغ است، نادیده گرفته می‌شود؛ کسی که دو هفته کمک کرده
و بعد چیزی گذاشته، خوانده می‌شود.

**متن پیام دیسکورد:**

```
Built a thing for a problem I kept hitting: explaining my Unity project
to an AI. Pasting scripts one at a time, then a screenshot of the
Inspector, then describing the Scene in words.

Unity DocSnap exports the whole project into one ai-bundle.md — every
Scene, Component and serialized field — plus an offline HTML site with
search and a health report (every missing script and broken reference,
with the exact object path).

Whole exporter is free, no time limit. Editor-only, nothing added to
your build, no dependencies.

github.com/AmirCollider/UnityDocSnap

Happy to answer anything. If it doesn't work on your project I'd
genuinely like to know why.
```

آن جمله‌ی آخر مهم است. دعوت به انتقاد، پست را از تبلیغ به گفتگو تبدیل می‌کند.

## ۵. ردیت — بدون آن نمی‌شود، ولی صبر می‌خواهد

r/Unity3D و r/gamedev بهترین جای این محصول‌اند. اکانتت بن شد و برنگشت.
راه درست، سه ماه است، نه سه روز:

```
ماه ۱   اکانت جدید. صفر تبلیغ. فقط جواب دادن به سؤال‌های یونیتی در
        r/Unity3D و r/gamedev. روزی دو جواب مفید. کارما بالا می‌رود.
ماه ۲   همان، به‌علاوه‌ی شرکت در تِرِدهای هفتگی «Share your work».
ماه ۳   یک پست. نه تبلیغ — یک نوشته‌ی فنی:
        «I built a tool that exports a Unity project for AI context.
         Here's what I learned about what LLMs actually need.»
        لینک در کامنت، نه در متن پست.
```

**اکانت را با VPN پایدار بساز و همیشه با همان IP وارد شو.** عوض شدن
مکرر IP، خودش دلیل بن شدن اکانت‌های جدید است.

اگر این سه ماه برایت طولانی است: هست. ولی r/Unity3D بیش از یک میلیون
عضو دارد و هیچ جایگزینی ندارد. هم‌زمان با کارهای دیگر انجامش بده،
نه به‌جایشان.

## ۶. یک شرکت واقعی برای بیرون‌سپاری

پرسیدی شرکت پیدا کنم. برای بازاریابی، صادقانه: **استخدام آژانس بازاریابی
اشتباه است.** با بودجه‌ی تو، آژانس‌ها یا جواب نمی‌دهند یا کاری می‌کنند
که خودت بهتر بلدی. تنها چیزی که ارزش خریدن دارد، **وقت تدوین** است:

| کار | کجا | هزینه‌ی تقریبی | پرداخت |
|---|---|---|---|
| ده ریلز از کلیپ‌های موجود | [LaborX](https://laborx.com) | ۸۰–۱۵۰ دلار | USDT ✅ |
| تصویر Social preview + کاور هایلایت | Fiverr / پونیشا | ۱۵–۴۰ دلار | گیفت‌کارت / ریالی |
| بازخوانی متن انگلیسی صفحه‌ی محصول | Fiverr (proofreading) | ۲۰–۳۰ دلار | گیفت‌کارت |

بیشتر از این خرج نکن تا وقتی اولین ده فروش را نکرده‌ای.
